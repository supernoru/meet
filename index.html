📡 GitHub Pages 무료 호스팅 (5분, 권장)
  1. github.com 가입 → 새 저장소(Repository) 만들기 (이름 예: meet, Public)
  2. 저장소 페이지에서 「Add file → Upload files」로 이 HTML 파일을 index.html 이름으로 업로드
  3. Settings → Pages → Branch를 main으로 선택 후 Save
  4. 1~2분 뒤 https://아이디.github.io/meet/ 주소로 누구나 접속 가능
  5. 카카오 개발자 콘솔의 플랫폼 Web 도메인에 이 주소를 등록하면 지도·검색도 모두 동작
